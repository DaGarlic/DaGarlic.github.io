ResNet ↗

Post-crisis resource allocation combining multimodal deep learning with DBSCAN spatial clustering.

PythonPyTorchCLIPReact
Technical details

Incoming posts are clustered geographically with DBSCAN, then each is encoded by CLIP ViT-B/32 into image and text embeddings. Those feed a 4-layer MLP (1024→512→256→5) for resource type, a ViT severity classifier, and two informativeness classifiers that filter out irrelevant posts before scores are aggregated per cluster. Served over a Flask REST/SSE API to a React + Leaflet map frontend.

Technical details

Implements minimax with O as the maximizer and X as the minimizer. Every terminal board state is scored (+1 O win, −1 X win, 0 draw), and each move recursively searches for the score an optimal opponent would allow, so the AI plays a provably unbeatable game.

Knight's Tour ↗

Backtracking with Warnsdorff's heuristic to solve the classic chess puzzle.

PythonAlgorithms
Technical details

Started as plain stack-based backtracking, which became impractical past a 7×7 board (10M+ iterations for one solution). Adding Warnsdorff's Rule — always moving to the unvisited square with the fewest onward moves — cut that dramatically, enabling exhaustive search across all variants (open/closed tours, every starting coordinate) with results streamed to disk to avoid memory blowup.
